# OSS Community Lab

Repository thực hành chuẩn hóa hồ sơ cộng đồng cho dự án mã nguồn mở.

## Mục tiêu

- Chuẩn hóa giấy phép mã nguồn.
- Xây dựng quy trình đóng góp.
- Thiết lập quy tắc cộng đồng.
- Thiết lập chính sách bảo mật.
- Tự động hóa Issue và Pull Request Template.

## Chạy chương trình

Yêu cầu: trình biên dịch GCC.

```bash
gcc main.c -o app
./app
```

Trên Windows PowerShell:

```powershell
gcc main.c -o app.exe
.\app.exe
```

Kết quả: `OSS Community Lab`.
